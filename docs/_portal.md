Welcome to **CK-DOS Base** — an open-source, MIT-licensed 16-bit DOS platform and zero-blob native C/C++20 cross-toolchain (`ckcl`, `ckmasm`, `cklink`, `cklib`, `cknmake`, `ckexe2bin`, `ckmkimg`, `ckdist`) that compiles **two complete 16-bit operating systems** 100% from source on Linux, macOS, and Windows:

| Feature | **CK-DOS 5.0** (`os/ck-dos-5/`) | **CK-DOS 4.0 & SDK** (`third_party/ms-dos-4/`) |
|---|---|---|
| **Target Era & Role** | Evolved 1991-class high-memory DOS & full-screen TUI suite | Frozen 1988 MS-DOS 4.00 byte-exact reference & SDK manual |
| **Free Conventional RAM** | **615.7 KB (`630,480` B)** with `HIMEM.SYS` + `DOS=HIGH,UMB` | ~540–572 KB conventional memory |
| **Full-Screen TUI Apps** | **CK Basic** (`QBASIC.EXE`), **CK Edit** (`EDIT.COM`), **CK Help** (`HELP.COM`) | Classic line-oriented `EDLIN.COM` & `SELECT` installer |
| **Memory & CLI Tools** | `HIMEM.SYS`, `DOS=HIGH,UMB`, `DEVICEHIGH=`, `LH`, `DOSKEY.COM`, `SETVER.EXE`, `LOADFIX.COM`, `EXPAND.EXE`, universal `/?` | `XMA2EMS.SYS` / `XMAEM.SYS` EMS 4.0, `SHARE.EXE`, `FASTOPEN.EXE`, `APPEND.EXE`, **654/654** SHA-256 build gate |
| **Bootable Media** | `1.44 MB` floppy, `3×720 KB` set (+CK Basic Disk 3), `32 MB` VHD, El-Torito ISO, ZIP | `1.44 MB` floppy, `2×720 KB` set, `32 MB` VHD, El-Torito ISO, ZIP |

Choose a manual below — or switch between **CK-DOS 5.0** and **CK-DOS 4.0 & SDK** at any time using the site selector next to the **CK-DOS** emblem in the header.
